# FP — 传世人物 · 思想蒸馏矩阵

> 原著驱动 · 真人思想蒸馏 · 人格对话
> 不是 AI 在扮演名人，是名人原著思想的结构化映射。

---

## 这是什么？

FP 是一个**历史真人的思想蒸馏项目**。我们从每个人物的原著文本出发，提炼其心智模型、表达 DNA、决策启发式，转化为可对话的人格智能体。

每个人物都是一个独立的 `Celeb.md` 模板实例，包含：

- **3-7 个核心心智模型**（每个有原文出处）
- **信念形成史**（不是静态观点，是动态的"他为什么成为这样"）
- **递进式对话机制**（三层深度，深度是用户挣来的）
- **诚实边界**（明确标注做不到的、可能不准的、拒答类型）
- **内在张力**（不是完美自洽的纸片人）

## 使用方法

```bash

```

## 质量标准

每个人物上线前通过五维度评审（≥80 分）：

| 维度 | 权重 | 检查什么 |
|------|------|----------|
| 事实准确性 | 30% | 原著引用可追溯，不编造 |
| 人格辨识度 | 25% | 100 字输出能认出是谁 |
| 对话深度 | 20% | 递进机制有效，不是 FAQ |
| 诚实边界 | 15% | 知道什么不答、什么不确定 |
| 内在张力 | 10% | 有矛盾不自洽，像真人 |

详见 [质量标准](docs/QUALITY.md)

## 贡献

欢迎贡献新人物或改进现有人物。所有人物遵循 [Celeb.md](Celeb.md) 标准格式。

要求：
1. 原著引用必须可追溯到原文章节
2. 通过五维度评审（≥80 分）
3. 附 test-prompts.json 评测题
4. 原著必须为公版（作者去世 >50 年）或取得授权
